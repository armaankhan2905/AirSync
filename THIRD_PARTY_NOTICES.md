# Third-party components and model provenance

Model binaries are downloaded explicitly from official sources by `scripts/fetch_models.py`. Runtime requires no network. Pinned paths and SHA-256 checksums are in `models/manifest.json`.

- **YuNet face detector**, `face_detection_yunet_2023mar.onnx`: OpenCV Zoo / Shiqi Yu and contributors, MIT. Source and license: https://github.com/opencv/opencv_zoo/tree/48b10fa505aeb51fbd127fc60a5c660040e823b7/models/face_detection_yunet . Full notice: `models/face_detection_yunet.LICENSE`.
- **SFace face recognizer**, `face_recognition_sface_2021dec.onnx`: OpenCV Zoo / Shenzhen Institute of Artificial Intelligence and Robotics for Society, Apache License 2.0. Source and license: https://github.com/opencv/opencv_zoo/tree/48b10fa505aeb51fbd127fc60a5c660040e823b7/models/face_recognition_sface . Full notice: `models/face_recognition_sface.LICENSE`.
- **MediaPipe Hand Landmarker**, float16 version 1: Google MediaPipe, Apache License 2.0. Official model: https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/1/hand_landmarker.task . Model documentation: https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker . Full source license: `models/mediapipe.LICENSE`.

InsightFace default pretrained weights are deliberately not bundled. This implementation uses OpenCV DNN CPU to execute ONNX face models with explicit published model-directory licenses. It does not require ONNX Runtime or an NVIDIA GPU.

The official [MediaPipe Hand Tracking model card](https://storage.googleapis.com/mediapipe-assets/Model%20Card%20Hand%20Tracking%20%28Lite_Full%29%20with%20Fairness%20Oct%202021.pdf) explicitly states Apache License 2.0. It also documents experimental/performance limits, occlusion concerns and intended hand-control uses. VisionGuard uses this hand model only for gesture input; it does not use hand landmarks to identify or surveil a person. Face matching uses the separately licensed SFace model.
